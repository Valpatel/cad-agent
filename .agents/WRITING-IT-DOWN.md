# Writing project lessons down

Search existing guidance first. Record new incidents in `.agents/inbox/YYYY-MM-DD-lesson.md` with a lesson-shaped heading, dated command/output evidence, cause, corrective rule and limits. Curate facts into domains, repeated procedures into playbooks, and recurring failures into issues. Update SYMPTOM-INDEX.md. Add regression checks where practical and carry the lesson in the related code review. Do not publish vendor archives or credentials.
