**Changed**
- `cadagent.review.gates.relations.relate` and the relation table decide a proven-apart pair from the distance first (#186). The faces must be more than `touch_mm` apart, one vertex of each connected set of either part's faces must lie outside the other, and `BRepAlgoAPI_Common` must come back empty. Such a pair is `apart` without volume integration, the cut or `BRepExtrema_DistShapeShape`'s per-vertex inner-solution test, which was most of the time. Every other pair takes the full path, unchanged. The README hero's clearance sweep on Gyropup's leg (811 pairs) gives the same state, gap, points and volumes for every pair in about half the CPU time; a many-faced apart pair is up to 25× faster.
- A distance-first `apart` has `witness.method = "distance-first"` and no `witness.volume_integration`, since nothing was integrated. The relation table now integrates a part only when one of its pairs needs its volume. Cached relations stay valid.
