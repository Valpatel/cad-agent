**New**
- `python3 tools/ci/preflight.py`: before pushing, lists the checks CI runs for the files a branch changes (since `origin/dev`, plus uncommitted ones, or `--paths`) and runs those this machine can. Checks it cannot run (a missing Playwright engine or build, a Python minor CI pins for a version-sensitive check, uninstalled Node dependencies, Windows) are reported as `not run` with the reason, never as passed; slow ones run with `--slow`. `--list`, `--json` and `--only` serve agents. The path-to-check mapping is `.github/ci-checks.json`, and `tests/repo/ci/test_ci_checks.py` fails when a pull-request workflow gains a check it does not mirror (#759).
