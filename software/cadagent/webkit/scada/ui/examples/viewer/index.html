Valpatel SCADA UI / standalone example

One system. Two views. Any host app.

Operate the fictional delivery pump and valve, then break the backup generator. Every view reads the same external model. All numbers and behavior are illustrative.

The same model, through a read-only adapter.

These controls are disabled because this adapter omits dispatch. Readings still change with the interactive viewer above.

The viewer owns rendering, selection, zoom and modals. The separate utility model owns commands, state and its clock.
